# Security Policy

## Supported Versions

The following versions of NumCompute-Stream are currently supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

If you discover a security vulnerability in NumCompute-Stream, please report it responsibly.

**How to report:**
- Open a **private** issue on the [GitHub repository](https://github.com/2100031988/numcompute-stream)
- Or contact the maintainer directly via GitHub

**What to include:**
- A clear description of the vulnerability
- Steps to reproduce the issue
- Any potential impact or exploit scenario

**What to expect:**
- You will receive an acknowledgement within **48 hours**
- A fix or patch will be reviewed and released within **7 days** if the vulnerability is accepted
- If declined, you will receive a clear explanation of why

We appreciate responsible disclosure and thank you for helping keep NumCompute-Stream secure! 🔒
